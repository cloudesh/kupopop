Kupopop Draw 0.1.0 is the first experimental build of the native drawing-and-guessing game.

- Welcome/account setup, private recovery codes, generated or hand-drawn avatars.
- Join Room, Make Room, and opt-in Public Rooms.
- Pencil, palette, fill, and eraser; up to 16 players, 90-second turns and two rounds by default.
- Server-authoritative solve-order/drawer scoring and isolated done-mode chat.
- Self-contained Windows x64/Linux x64 servers with startup launchers and TLS hosting setup.
- Local file diagnostics with credentials, answers, and chat content excluded.

Requires Dalamud API 15 and a running Kupopop server. Default plugin endpoint is https://localhost:7443.
This release has automated tests and compile verification; in-game testing is still required.
Only three prototype words are included. No persistent Kupo-Points or Lodestone verification yet.

See TESTING.md and server/HOSTING.md in the repository for installation, recovery, logs, and hosting instructions.
