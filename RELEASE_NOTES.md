Kupo Skribbl 0.9.3 restores the paper silhouette while keeping native movement.

- The standard Dalamud title bar and frame are hidden in normal use and visible only in the debug view.
- Empty paper uses ImGui's native dragging. No custom drag zones or position controller are used.
- Pin and close actions return to the paper header; closing still disconnects from the server and room.

Open /kuposkribbl debug to show the standard frame for diagnostics. In-game dragging and rendering require player verification.
