Kupo Skribbl 1.0.0

A drawing-and-guessing party game inside Final Fantasy XIV for 2–16 players.

- Profile now opens with your portrait, name and lifetime game record. Choose Change profile picture to open the drawing editor.
- Cancel picture changes restores your saved portrait. Saving profile details from the preview preserves existing avatar pixels and presets.
- Homepage notes have subtle opposing angles; inputs and buttons remain level and easy to click.
- Includes private/public rooms, FFXIV and general word lists, unranked custom words, friends, invitations, drawn avatars, drawing likes and optional lifetime leaderboards.
- Open with /kupo, /kuposkribbl or /kupopop.

Install through the custom repository in the README. Version 1.0 does not indicate official Dalamud repository approval. API 15, protocol 5; existing accounts and privacy preferences remain unchanged. No backend update is needed.

Automated checks and native previews run outside FFXIV; the maintainer still needs to verify the final revision in-game.
