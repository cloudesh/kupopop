Kupopop Draw 0.2.1 makes the drawing room smaller and gives the page more space.

- Compact 980 x 650 default window, one-row navigation, and reduced panel/field spacing.
- Narrower player/chat panels, explicit panel-height bounds, and no fixed empty toolbar space above spectator canvases.
- Layered sheet edges and subtle paper grain from FFXIV's Mogpendium UI. Drawing pixels stay white and accurate.
- Painted moogle artwork with transparent edges replaces the square minion item tile.
- Pencil, fill bucket, and eraser icons with tooltips; wider brush-size control.
- Compact Public Rooms heading and list; more room for avatar drawing.
- File diagnostics include displayed canvas dimensions and mascot-load results.

Requires Dalamud API 15 and a running Kupopop server. The default endpoint remains https://localhost:7443.
Protocol 1 remains compatible with the previous server. Three prototype words remain; no persistent Kupo-Points or Lodestone verification yet.
Compiled and automatically tested; in-game rendering/input testing is still required.

The old window dimensions reset once for this compact layout. Subsequent resizing is retained.
See TESTING.md, UI_DESIGN.md, and server/HOSTING.md for usage, appearance, logs, and hosting.
