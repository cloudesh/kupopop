Kupopop Draw 0.2.0 brings a consistent native stationery interface to the drawing room.

- Warm parchment, dark ink, brass borders, and a restrained moogle-pink accent.
- Redesigned welcome, recovery, play menu, room setup, public rooms, profiles, and game view.
- Shared drawing/avatar toolbar, clearer player roles, done-mode messaging, and separate connection/diagnostic settings.
- Start is disabled until two players connect; rejected actions have safe diagnostic reason codes.
- Permanent Start-My-Server.cmd workspace launcher and private state storage; release ZIPs exclude host data, certificates, logs, and proxy caches.

Requires Dalamud API 15 and a running Kupopop server. The default endpoint remains https://localhost:7443.
Protocol 1 remains compatible with the previous server. Three prototype words remain; no persistent Kupo-Points or Lodestone verification yet.
Compiled and automatically tested; in-game rendering/input testing is still required.

See TESTING.md, UI_DESIGN.md, and server/HOSTING.md for usage, appearance, logs, and hosting.
